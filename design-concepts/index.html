Three dashboard structures

Structurally different, not reskins. Same data — the real get_admin_metrics_v1 shape, plus the live-orders query. Same tokens from packages/ui: burnt orange #B54708, IBM Plex Sans + Arabic.

The figures are sample peak-service values so you can judge the design under load. The live database currently holds 1 order and near-zero totals, which makes any dashboard look dead and tells you nothing about the layout. Every number comes from a field that actually exists. Open each file directly, or press a key to flip between them.

A

The Dispatch Desk

A permanent attention queue down the left, live orders as the centre. Answers "what is on fire, then what is running" in that order, without scrolling.

The Split Board

Two thirds is the queue you act on. One third is a permanent reference rail — money, today, capacity — never scrolled. Answers "act fast, know everything without moving".
